# AiNews monitoring

Spring Boot Actuator metrics are exposed on the separate management port `9091`.
The application load balancer and ECS security group do not expose this port.

## Start locally

1. Start the backend on the host. The metrics endpoint is
   `http://localhost:9091/actuator/prometheus`.
2. Set a Grafana administrator password in the current shell.
3. Start the monitoring stack.

```powershell
$env:GRAFANA_ADMIN_PASSWORD = '<strong-password>'
docker compose -f monitoring/docker-compose.yml up -d
```

- Prometheus: `http://127.0.0.1:9090`
- Grafana: `http://127.0.0.1:3001`
- Grafana user: `admin`

The provisioned `AiNews Service Overview` dashboard includes HTTP traffic,
p95 latency, 4xx/5xx ratios, database write-intent requests, HikariCP pool
usage, JVM memory, and process/system CPU.

## Change the scrape target

Edit `prometheus/targets.json`. A target is only `host:port`; the metrics path
is configured separately in `prometheus/prometheus.yml`.

For Linux, Compose maps `host.docker.internal` to the Docker host gateway.
When running the backend outside ECS, restrict access to port `9091` with the
host firewall. In ECS, port `9091` is excluded from ALB listener rules and is
reachable only between instances in the ECS container-instance security group.

## ECS monitoring

Terraform also runs Prometheus and Grafana together as an ECS monitoring task.
The backend management port is registered in the private `ainews.local` Cloud
Map namespace. Prometheus discovers every backend task through SRV records and
scrapes the dynamic management ports without exposing them through the ALB.

Prometheus uses task-local storage because its TSDB does not support NFS/EFS.
Metrics reset if the single Spot monitoring task is replaced; dashboards remain
reproducible because they are provisioned from the Grafana image. Grafana is
available through the CloudFront `/grafana/` path, and its administrator
password is generated by Terraform and stored in Secrets Manager.
Set `app_base_url` to the deployed CloudFront or custom-domain URL so Grafana
generates correct `/grafana/` redirects.

After deployment, an operator with Secrets Manager permission can locate the
credential through the sensitive `grafana_admin_secret_arn` Terraform output.
